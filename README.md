
#BestyKitchen — BEFRS Recipe Companion Site

A fan project companion site for Best Ever Food Review Show, with recipe archiving and a spice store foundation.
What's included: 
index.html - Public recipe listing page, 
recipe.html - Individual recipe detail page, 
admin.html - Private admin panel to add/edit recipes

Create a new GitHub repo called bestykitchen (or any name)
Upload all 3 HTML files to the repo
Go to Settings → Pages
Under "Source", select Deploy from a branch → main → / (root)
Click Save — your site will be live at https://YOUR-USERNAME.github.io/bestykitchen

That's it. The site uses localStorage, so all recipes are stored in your browser — no backend needed.
How to add recipes

Go to yoursite.github.io/bestykitchen/admin.html

Fill in the recipe manually, OR paste the YouTube transcript and click Extract Recipe from Transcript to auto-fill
Upload a photo of the dish (drag & drop supported)
Click Save Recipe

YouTube transcript tip
On YouTube:

Open the video
Click the ⋯ (three dots) below the video
Click Show Transcript
Select all the text and copy it
Paste it into the transcript box in the admin panel

Notes
